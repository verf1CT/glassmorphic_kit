# Glassmorphic Kit for Figma

Welcome to the official Figma plugin for the **Glassmorphic Kit** Flutter package!

## What is this?
This plugin allows designers and developers to seamlessly bridge the gap between UI design in Figma and implementation in Flutter. It reads the properties of your selected Figma layers (such as background blur, opacity, border radius, and colors) and instantly generates production-ready Dart code using the `AnimatedGlassContainer` widget.

## How to use
1. Select any Rectangle or Frame in your Figma canvas that uses `BACKGROUND_BLUR` effects.
2. Open the **Glassmorphic Kit** plugin.
3. The plugin will instantly analyze the layer and show you the generated Dart code.
4. Click **Copy to Clipboard** and paste it directly into your Flutter project!

## Requirements
To use the generated code, make sure you add the package to your Flutter project:
```bash
flutter pub add glassmorphic_kit
```
